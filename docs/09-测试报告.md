## 5. 上线建议

- **不建议直接上线**：存在 2 个 P0 严重缺陷（BUG-002 影响营销、BUG-003 影响资金）
- **修复后回归**：BUG-001/002/003 修复 → 自动化套件回归 → 手工 CP-01/ORD-04/CP-03 复测 → 抓包专项复跑
- **遗留风险（持续跟踪）**：
  1. 本地 HTTP 明文传输（生产环境必须 HTTPS）
  2. 内存版未做持久化（生产需 MySQL）
  3. 未做并发库存扣减的分布式场景测试
  4. Mock 支付未覆盖真实渠道（微信/支付宝回调）
