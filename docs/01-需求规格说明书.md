# MiniMall 商城需求规格说明书（节选）

| 版本 | 日期 | 作者 | 说明 |
|---|---|---|---|
| V1.0 | 2026-09-06 | 产品组 | 首版 |

## 1. 项目背景

MiniMall 是一个极简电商平台，本期（V1.0）交付核心交易链路：**登录 → 浏览商品 → 加购 → 下单（支持优惠券）→ 支付**。

## 2. 功能需求

### 2.1 登录
- FR-101：用户使用用户名 + 密码登录，成功后下发 token，后续接口凭 token 访问。
- FR-102：用户名或密码为空、用户不存在、密码错误，均需返回明确错误提示。
- FR-103：未携带有效 token 访问交易接口，返回 401。

### 2.2 商品
- FR-201：商品列表展示名称、价格、库存。

### 2.3 购物车
- FR-301：加购数量必须为**正整数**，且 ≤ 当前库存，否则拒绝并提示。
- FR-302：购物车展示各商品小计与订单合计金额，金额精确到分。

### 2.4 下单与优惠券
- FR-401：购物车非空才可下单；下单成功后扣减库存、清空购物车，订单状态为"待支付"。
- FR-402：优惠券 MAN30JIAN10 规则为**满 30.00 元减 10.00 元**（含 30.00 整）。
- FR-403：**防重**：同一购物车的重复下单请求不得产生多笔订单（幂等）。
- FR-404：金额关系必须满足：实付 = 合计 − 优惠。

### 2.5 支付
- FR-501：仅"待支付"订单可支付，支付后状态变更为"已支付"。
- FR-502：用户不能操作他人订单。

## 3. 非功能需求
- NFR-01：核心接口（下单/支付）响应时间 P95 < 500ms。
- NFR-02：弱网（3G 水平）下接口有明确超时与错误提示，不产生脏数据。
- NFR-03：token 等敏感信息不得出现在 URL、日志明文中。
